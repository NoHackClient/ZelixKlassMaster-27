Overview

The Zelix KlassMasterTM ProGuard Configuration Translate tool allows you to translate a ProGuard configuration file into a ZKM Script. Not every ProGuard configuration option is supported.

ProGuard configuration file "Open" button

Click on this button to open a file dialog so that you can select the existing ProGuard configuration file that you wish to translate.

"Paste" button

Click on this button to paste the contents of the System clipboard into the "Open a ProGuard configuration file or paste contents into here....

"Open a ProGuard configuration file or paste contents into here..." area

Paste ProGuard configuration content that you wish to translate into this area or open an existing ProGuard configuration file.

"Save" button

Click on this button to save the contents of the "Translated ZKM Script will appear here" area to a file.

"Copy" button

Click on this button to copy the contents of the "Translated ZKM Script will appear here" area into the System clipboard.

"Translated ZKM Script will appear here" area

The result of the translation will appear in this area after you have clicked the Translate button.

Translate button

Click this button to perform the translation. It will be disabled until you have opened or pasted contents into the "Open a ProGuard configuration file or paste contents into here..." area.
