Overview

This dialog allows you to choose the change logs to be used.

Change log list

The list of change logs. A change log high in the list takes precedence over those below it.

"Add" button

Click the "Add" button to open a file dialog. The dialog will allow you to select new change logs to add to the list.

"Remove" button

Removes the selected change log from the list.

"Move Up" button

Moves the selected change log upwards within the list. The list order represents the search order. Change logs at the top will be used first.

"Move Down" button

Moves the selected change log downwards within the list. The list order represents the search order. Change logs at the bottom will be used last.

"Import" button

Allows you to import a list of paths from a line delimited text file.

"Export" button

Allows you to export the list of paths to a line delimited text file.
