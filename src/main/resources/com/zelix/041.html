Overview

The Zelix KlassMasterTM "Obfuscate References" tool obfuscates references to fields and methods. Obfuscate reference inclusions specify the field and method references that should be obscured by the "Obfuscate References" tool. If you do not specify any obfuscate reference inclusions then no references will be obscured.

Field inclusion parameters

An inclusion parameter that includes a field reference for obscuring.

Method inclusion parameters

An inclusion parameter that includes a method reference for obscuring.

Inclusion parameter list

Shows the current inclusion parameters. The form of the inclusion parameters is the ZKM Script syntax where the "*" character is a wildcard.

Add button

Click this button to add an inclusion parameter to the "Inclusion parameter" list.

Modify button

Click this button to modify the selected inclusion parameter in the "Inclusion parameter" list.

Delete button

Click this button to delete the selected inclusion parameter in the "Inclusion parameter" list.

Explanation area

Displays a plain language explanation of the effect of the selected inclusion parameter in the "Inclusion parameter" list.
