Overview

Use this dialog to choose the type of parameter that you wish to add to the Obfuscate References Inclusion window's "Inclusion parameter" list.

Select the "Field" radio button if you wish to add an inclusion parameter that will specify references to fields that you want obscured.

Similarly, select the "Method" radio button if you wish to add an inclusion parameter that will specify references to methods that you want obscured.
